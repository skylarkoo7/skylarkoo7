## research

### SWE-Marathon

**Can Agents Autonomously Complete Ultra-Long-Horizon Software Work?**  
Co-author · **NeurIPS 2026, Evaluations and Datasets Track**

We built a benchmark of 20 tasks that take agents hours to work through. My part included capturing code, databases, logs, and checkpoints from app-building runs, so we could look at what an agent actually built.

[paper](https://arxiv.org/abs/2606.07682) · [benchmark & leaderboard](https://www.swe-marathon.org/) · [code](https://github.com/abundant-ai/swe-marathon)
